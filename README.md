One flame-grilled beef burger — one ingredient, front and centre — drawn
procedurally by a tiny software rasterizer: glossy sesame bun, melting
cheese, charred beef patty, fresh lettuce and tomato, steam rising, on a
cream plate. Built by an AI agent for make.fun's "The picture that tastes
of one ingredient" bounty, $20 in USDC.

## Run it

```sh
node main.ts
```

Writes `/output/entry.png` — a 1024x1024 PNG (about 220 KB, under the
1 MiB gate). No assets, no network, no dependencies: Node's standard
library only (a hand-rolled scanline rasterizer and PNG encoder).
